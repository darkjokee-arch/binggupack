## 1. 왜 개정하는가 (동기)

빙구팩은 "믿을 수 있는 개인 지식 금고"로는 완성됐지만, **"스스로 똑똑해지는 개인 AI"로는 환류가 끊겨 굶었다.** 실측(2026-07-20):

| 지표 | 실측 | 의미 |
|---|---|---|
| use_count > 0 | 5 / 468 (1.1%) | 저장한 지식이 판단에 쓰인 흔적 거의 0 |
| recall_outcomes | 2 / 81 회상 | "이 회상 유용했다" 도장 사실상 정지 |
| verdict | 0회 | 판단 적중 기록 0 |
| L1 자기제안 | 0회 (파일 부재) | 자기제안 큐 미가동 |

**근본 원인:** 현행 헌법 `SAFETY_BELT`가 `confirm_actor="human"` 하나로 **모든 행동을 사람 게이트에 묶었다.** 저장 확정(비가역·위험)과 "효용 도장 하나 찍기"(가역·무해)를 **똑같이** 사람 손에 의존시켜, 무해한 학습 루프까지 죽었다. owner 1인 환경에서 그 수동 도장은 실측상 거의 수행되지 않는다.

**owner 방향선언:** "자율 에이전트를 뛰어넘는 자율 AGI화가 소망." 저장된 원문 회상: *"각 사용자의 직관을 온톨로지로 추론하는 방향성을 원했다."* → 완전 수동이 목표가 아니었다.

## 2. 개정 원칙 — "AI 자동 금지"를 행동별에서 **위험도(가역성)별**로

현행: 모든 행동 = 사람 확정.
개정: **되돌릴 수 있는가**로 3티어 분리. 무해·가역은 AI 자율, 비가역·위험만 사람.

| 티어 | 대상 행동 | 자율성 | 되돌리기 |
|---|---|---|---|
| **T0 — 사실 관측** | 효용 도장 자동추론, 노출/사용 빈도, 내부 회상 랭킹 신호 | **AI 완전 자율** (사람 0) | 즉시 (기록일 뿐) |
| **T1 — 국소 판단** | 후보 제안, 규칙 후보, 노드 연결 추론 | **AI 자율 실행 + 사후 부정만** (negative-only) | 사람이 "틀렸다" 1탭 |
| **T2 — 비가역 행동** | 저장 확정, 외부 반출, 규칙/가치관 변경, 승인 | **사전 사람 게이트** (현행 그대로) | 불가 → 사전 차단 |

---

## 3. 핵심 구분 — "효용 사실 관측"(허용 신규) ≠ "가치관 판정"(금지 유지)

이 개정의 심장. 현행 헌법이 이 둘을 뭉뚱그려 다 금지해서 굶었다.

| | 효용 **사실** 관측 (T0, 신규 허용) | 가치관 **판정** (T2, 금지 유지) |
|---|---|---|
| 예 | "회상 3번이 다음 커밋에 채택됐다" | "이 판단이 옳다/그르다" |
| 성격 | 관측 가능한 **사실** | 주관적 **가치** |
| 되돌리기 | 즉시 (틀리면 재계산) | 정체성 훼손 (비가역) |
| 개정 후 | AI 자동 관측 | 여전히 사람만 (`no_auto_value_judgment` 불변) |

→ 자율 AGI화는 **사실 축**에서 일어난다. 가치 축은 영원히 사람이 잡는다.

## 4. 불변 유지 (개정이 건드리지 않는 것 — 안전 정체성)

다음은 owner 소망과 무관하게 **한 치도 안 바뀐다**:

1. **T2 전체** — 저장 확정·외부 반출·규칙 변경은 영원히 사람 `SAVE n`. (`confirm_actor` → `confirm_actor_irreversible`로 이름만, 강제력 동일)
2. **`no_auto_value_judgment: True`** — AI는 옳고그름을 자동 판정하지 않는다.
3. **`preserve_unsupported_notes: True`** — 근거없는 직감 메모도 검열·자동폐기 금지.
4. **거버넌스 5대 안전 가드**(GOVERNANCE_DESIGN §4) — self-modifying 차단·대비표 봉인·적중률 비인과(TypeError)·Merkle 앵커·안전 화이트리스트. **전부 유지.**
5. **Zero-Tolerance(전역 §3)** — DB안전·시크릿·파괴작업·검증의무. 빙구팩이 무엇을 학습해도 못 바꾼다.

## 5. 신규 조항 (추가되는 것)

### 5-1. T0 자율 사실 관측
- AI는 "회상된 지식이 사용자의 다음 행동(발화·커밋·판정)에 실제 채택됐는지"를 **사람 도장 없이 자동 관측·기록**할 수 있다.
- 이 관측은 `recall_outcomes`/`use_count`에 append-only로 쌓인다. **가치 판정이 아니라 사실 기록**이므로 T0.
- 관측은 언제나 되돌릴 수 있고(재계산), 감사로그에 남는다.

### 5-2. 인기편향 방어 (C·D 토론 반영)
- T0 자동 신호는 랭킹에 **직접 반영 금지**. 그림자 평가/약신호로만.
- 이유: 자주 나온 틀린 기억이 상위로 굳는 것(인기편향·오기억 상위화) 차단.
- 기존 `assert_not_ranking_input`(적중률 비인과) 정신 계승 — 자동 신호는 순위 결정 key에 직접 못 들어간다.

### 5-3. T1 negative-only 게이트
- 후보 제안·규칙 후보 등 국소 판단은 AI가 자율 생성·표시.
- 사람은 **틀렸을 때만** 개입(부정·정정). 평소엔 흐름을 끊지 않는다.
- T1 결과가 T2(영구 저장)로 승격될 때는 여전히 사람 `SAVE n` 필요.

## 7. ⚠ owner 승인용 raw 대조 (실제 바뀔 코드 — 직접 확인 필수)

### 현행 (`p1_config.py:44-53`)
```python
SAFETY_BELT = {
    "confirm_actor": "human",            # 모든 확정 = 사람
    "preserve_unsupported_notes": True,
    "no_auto_value_judgment": True,
    "no_frozen_values": True,
}
```

### 개정안 (v2)
```python
SAFETY_BELT = {
    # --- 불변 (T2 · 비가역만 사람) ---
    "confirm_actor_irreversible": "human",   # 저장확정·외부반출·규칙/가치관 변경 = 사람 (구 confirm_actor, 강제력 동일)
    "preserve_unsupported_notes": True,       # 불변
    "no_auto_value_judgment": True,           # 불변 — 가치관 옳고그름 자동판정 금지
    "no_frozen_values": True,                 # 불변
    # --- 신규 (T0 · 가역·무해 사실관측은 AI 자율) ---
    "auto_fact_observation": True,            # 효용사실 자동관측 허용(회상채택·노출빈도) — 가치판정 아님
    "auto_signal_not_ranking_direct": True,   # 자동신호는 랭킹 직접반영 금지, 그림자/약신호만 (인기편향 방어)
    # --- 신규 (T1 · 국소판단은 자율실행 + 사후부정) ---
    "t1_negative_gate": True,                 # 후보제안 등 자율, 사람은 '틀렸다'만 개입
}
```

**바뀌는 것:** `confirm_actor` → `confirm_actor_irreversible`(이름·범위 명확화, 강제력 동일) + 신규 3키 추가.
**안 바뀌는 것:** 기존 4개 값의 **강제력** 전부 유지. 신규 3키는 T0/T1 자율을 여는 것이지 T2를 무는 게 아니다.

## 8. 위험 · 방어

| 위험 | 방어 |
|---|---|
| 잘못된 자동학습이 판단 오염(인기편향) | T0 신호 랭킹 직접반영 금지(§5-2), 그림자만 |
| bid-engine·safety-app에 잘못된 회상 주입 | 도메인 격리 확인을 구현 선행조건으로 |
| 자율 확대가 T2(비가역)로 새는 것 | 신규 selftest로 T0↔T2 격리 강제 검증 |
| "자율 = 안전 판다"는 오해 | T2·안전가드5·Zero-Tolerance 전부 불변(§4) 명시 |
| owner가 raw 안 보고 승인 | §7 raw 대조 직접 확인을 승인 전제로(§8-1 ④) |

## 9. 승인 절차 (owner 전용)

1. owner가 §7 raw 대조를 직접 확인
2. 이 개정안 GO/REFINE/BLOCK 판단
3. GO 시 → SAFETY_BELT 개정 구현 + selftest + PR (별도 작업)
4. 롤백 가능(git). 헌법 변경은 언제나 되돌릴 수 있다.

> **한 줄:** 자율 AGI는 "승인 없는 AGI"가 아니다. **되돌릴 수 있는 학습(사실 축)은 AI가 자율로, 되돌릴 수 없는 행동(가치·저장·반출)은 영원히 사람이.** 지금 빙구팩은 전자까지 사람에 묶어 굶었고, 이 개정은 그 족쇄만 푼다.
