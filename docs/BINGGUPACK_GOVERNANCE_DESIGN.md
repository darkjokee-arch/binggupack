# BingguPack — 자기진화 거버넌스 (Self-Evolving Governance) 설계

> v1.13.0 신기능. 빙구팩 학습과 기존 규칙(강제조항)이 충돌할 때 — **빙구팩은 양쪽을 보여주고 제안만, 규칙 변경의 마지막 손은 사람.** 빙구팩이 거버넌스 자산(규칙·정책)을 직접 수정하지 않는다(self-modifying 0).

## 1. 왜 필요한가

빙구팩은 사용자의 판단·선호를 쌓는다. 그런데 그 학습이 기존 규칙(프로젝트 규약·정책·축적된 교훈)과 어긋날 때 — 학습이 후순위로 밀려 사장되거나, 반대로 빙구팩이 멋대로 규칙을 바꾸면 위험하다. 이 사이를 안전하게 잇는 게 거버넌스다.

핵심 질문: **"빙구팩이 더 나은 판단을 학습했을 때, 그걸 어떻게 규칙에 반영하되 빙구팩이 자기 규칙을 조작하지 못하게 하나?"**

## 2. 3단 + 세션 마무리

| 단계 | 하는 일 |
|---|---|
| **1. 대비(Contrast)** | 빙구팩 학습 ↔ 기존 규칙이 충돌하면 **양쪽을 동일 양식·원문 그대로** 보여주고 사람이 선택. 자동 결정 0. (안전/무결성 충돌은 대비 제외 — 규칙 그대로) |
| **2. 검증(Track)** | 사람의 선택 결과를 적중률로 기록. 단 적중률은 **"참고 신호"일 뿐 결정 근거 아님**(상관≠인과·맹종 금지) |
| **3. 진화(Evolve)** | 빙구팩이 어떤 규칙보다 반복 우위면 **제안만 표시** → 사람이 진짜(raw)를 직접 확인 → 승인 → 규칙 변경(롤백 가능). **빙구팩은 규칙 파일에 손대지 않음** |
| **세션 마무리** | 세션 끝 발화(사용자마다 다름·키워드 아닌 의미 감지) 시 저장 preview + 거버넌스 정리(대비·적중률) 표시. **저장은 사람 SAVE만** |

## 3. 대원칙 — self-modifying 회피

3라운드 다중 모델 토론(4cli) 결론: **빙구팩이 거버넌스 진화에 같은 런타임으로 관여하면, 메모리/실행 격리 없이 무결성을 보장할 수 없다**(빙구팩이 자기 평가·화면·판정을 만지면 조작 가능).

→ 안전 착지: **빙구팩은 "제안·기록"만, 규칙 변경은 사람이 빙구팩과 무관하게.** 빙구팩이 거버넌스 자산(규칙/정책/축적 교훈/그래프)에 write 0(read-only).

## 4. 5개 안전 가드 (전부 코드로 강제·검증 통과)

1. **self-modifying 차단** — 거버넌스 자산 경로를 `realpath` 물리 가드로 막음(symlink/junction 우회 차단·capability-removal).
2. **대비표 원문 봉인** — 빙구팩이 보여주는 표가 원문과 일치하는지 byte-parity 검증(조작 시 fail).
3. **적중률 비인과** — 적중률을 정렬·순위·결정 key에 넣으면 `TypeError`(코드 차단). 신호로만.
4. **무결성 앵커(Merkle)** — 적중률 장부를 같은 트랜잭션에 봉인·full64 해시·외부에서 raw 재계산 가능·누락 fail-closed.
5. **안전 화이트리스트** — 안전 조항(DB안전·시크릿·파괴작업·검증의무)은 코드 상수로 교체 불가 강제·"스타일로 위장" 차단·정책 pin fail-closed.

## 5. 구현 (stdlib only)

| 모듈 | 역할 |
|---|---|
| `binggu_contrast_protocol.py` | 1단 대비 — 충돌 감지·대비표·원문 봉인 |
| `binggu_hit_stats.py` (확장) | 2단 적중률 — 비인과 불변식·domain·신호화 |
| `binggu_merkle_anchor.py` | 2단 무결성 — atomic 봉인·외부 재계산 |
| `binggu_policy.py` + `policies/binggu_policy.json` | 안전 화이트리스트·정책 pin |
| `binggu_hit_export.py` | 3단 분리 — raw export·거버넌스 write 물리 차단 |
| `binggu_session_close.py` | 세션 마무리 — 의미 감지·저장 preview |

검증: 가드 5/5 통과 · selftest 전수 GO(hit_stats 12 · merkle 13 · hit_export 8 · staging 17 · binggu 40) · 거버넌스 write 0 · 운영 장부 마이그레이션 무손상.

## 6. 한 줄

**빙구팩은 똑똑한 비서처럼 "이게 더 나아 보여요" 조언하고, 충돌하면 양쪽을 펼쳐 보여주지만 — 규칙을 바꾸는 도장은 항상 사람이 찍는다. 그리고 안전 규칙은 빙구팩이 무엇을 학습해도 못 바꾼다.**
