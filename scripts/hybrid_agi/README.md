# Hybrid-AGI — 사람 승인형 개인 추론 (human-gated reasoning)

빙구팩의 개인 지식 그래프를 **"AI가 생각(추론)하되, 사람이 최종 결정"** 하는 방식으로 키우는 모듈입니다.

## 한 줄 요약

> AI는 **후보를 던지는 역할**(권위 0). 사람이 **먼저 답**하고 → AI 제안을 보고 → 비교 → **도장**.
> **도장 찍은 것만 영구 저장** = "내가 고른 것만 내 지식".

이렇게 하면 두 가지를 동시에 지킵니다:
- **추론(AGI)**: AI가 흩어진 점들에서 *없던 연결·명제를 새로 만듦*(검색이 아님)
- **정체성(주권)**: 저장은 사람 도장만 — AI가 멋대로 못 넣음

## 계층 구조

| 층 | 내용 |
|---|---|
| **L0** | 사람이 SAVE한 원문 노드 (**절대 불변** — AI가 쪼개거나 수정 안 함) |
| **L1** | 원자 명제 (사람 추출 또는 AI 제안 + **사람 도장**) |
| **L2** | 추론 엣지 (`depends_on`, `contradicts` …) — AI 제안 + 사람 도장만 영구 |

## 안전장치 — 블라인드 대조 + 봉인(commit-reveal)

AI가 사람 생각을 *미리 물들이는 것*을 막는 핵심:

1. AI 제안을 **봉투에 봉인**(seal) — 사람은 내용 못 봄
2. 사람이 **먼저 자기 답**을 확정(commit)
3. 그제서야 AI 제안 **공개**(reveal) → 비교
4. 사람이 도장 → 영구

- **순서 위조 차단**: 봉인↔질문 바인딩(fail-closed) + 내부 단조 카운터로 *실제 호출 순서* 강제 (시계 숫자 조작 무력화)
- **베껴쓰기 탐지**: 사람 답이 AI 제안과 같으면 의심 플래그 → 도장 차단
- **증명서 위조 차단**: HMAC(사용자별 키)로 손으로 만든 증명서 거부

## 사용자별 비밀키 (공개 도구 핵심)

증명서 위조를 막는 HMAC 키는 **사용자마다 달라야** 합니다(공개 코드에 박으면 누구나 위조 가능).

- 처음 실행 시 **자동으로 랜덤 키 생성** → `~/.binggupack/hybrid_agi/` (권한 0600, **git 저장소 밖**)
- 키는 절대 출력·로그·커밋 안 됨 (hash 일부 + 길이만 노출)

## 한계 (정직하게)

기술이 못 막는 두 가지 — 솔직히 적어둡니다:

1. **사이드채널**: 사용자가 *다른 경로*(별도 AI 세션 등)로 제안을 미리 보고 와서 답하면 코드로 못 막습니다 = **사용자 자기규율**. 봉인은 "시스템 안 순서"만 보장.
2. **베껴쓰기 정밀도**: 공백·대소문자 편집은 잡지만, 구두점·단어 치환·의미 유사는 못 잡습니다. **사람 도장이 최종 게이트**.

## 빠른 시작

```bash
# 통합 동작 확인
python scripts/hybrid_agi/hag_orchestrator.py --selftest   # GATE: GO

# 개별 모듈 검증
python scripts/hybrid_agi/hag_commit_reveal.py --selftest
```

모든 selftest는 **임시(temp)·메모리에서만** 돌고 운영 장부(`~/.binggupack/ledger.sqlite`)는 건드리지 않습니다.

## 모듈 (9개)

| 파일 | 역할 |
|---|---|
| `hag_orchestrator.py` | 통합 파이프라인 (L0→L1→L2 + 블라인드 흐름 + 키 자동 로드) |
| `hag_commit_reveal.py` | 봉인/공개 + HMAC 증명서 + 순서 강제 |
| `hag_blind_ledger.py` | 변조 불가 기록 (hash-chain, append-only) |
| `hag_l1_proposition.py` | 명제층 (L0 불변·파생만) |
| `hag_l2_edge.py` | 추론 엣지 (매트릭스 검증·사람 도장) |
| `hag_token_guard.py` | 비용 방어 (그래프 증분 — N² 폭증 회피) |
| `hag_drift_metrics.py` | 오염 자동 차단 (임계 초과 → 동결, 가역) |
| `hag_meta_monitor.py` | 장기 감시 (발화 정형화 추이, 경고만) |
| `hag_keyring.py` | 사용자별 비밀키 자동 생성·안전 저장 |

## 설계 배경

"개인 AGI"라는 목표 안에 숨은 **근본 모순** — *"사람이 다 정하면(정체성) 추론이 아니고, AI가 정하면(AGI) 정체성이 깨진다"* — 을 4cli 6라운드 토론으로 짚고, **하이브리드(AI 제안 → 사람 도장)**로 해소한 결과물입니다.

원칙: 노드(사람이 고른 문장 전체) 불변 · 자동 저장 0 · 사람 도장만 영구 · 운영 장부 보호.
